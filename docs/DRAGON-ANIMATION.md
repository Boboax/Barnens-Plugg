# Crystal dragon animation quality sample

Built-in ImageGen produced eight hand-painted poses in a 4×2 sheet, using the existing crystal dragon as the identity/style reference. The generated background contained an opaque checkerboard; `work/prepare-dragon-animation.py` removes it locally, preserves isolated highlights and registers the feet. Each atlas cell is 480×480 pixels. The original PNG is retained unchanged.

Files: `public/art/camp/crystal-dragon-idle-v2.webp` (eight frames, real alpha), `crystal-dragon-idle-poster-v1.webp` (static fallback), `src/ui/components/CrystalDragon.tsx`, `src/styles/crystal-dragon.css`.

The animation uses discrete sprite frames for a blink, small head movement, wing opening and tail movement. It does not scale, rotate or translate the entire dragon image. A 5.8-second idle cycle has a quiet rest; touching the dragon plays a shorter 0.85-second sequence. This is a first animation sample, not a final rig. Other pets retain their existing implementation until this sample is reviewed.

The atlas is preloaded before playback. Reduced-motion preferences and the camp pause control show the neutral pose. No saved game fields change. The atlas is approximately 1.2 MB and loads once per page/cache lifecycle.

## ImageGen prompt

Create a production animation SPRITE SHEET for the exact baby crystal dragon in the reference. 4 columns by 2 rows, 8 equal square cells, ideally 2048x1024 or higher. Transparent background with real alpha, NO checker pattern, NO scenery, NO shadows on ground, NO text or cell borders. Preserve this exact beautiful painterly lilac scaled dragon, gold eyes, pale yellow chest, crystal horns, curled tail and small purple wings. Fixed camera and lighting, three-quarter facing right. Every frame SAME scale, same seated feet registration, head crystal tops clear of cell edges. Each full-body dragon fits inside 88% cell height. These are consecutive subtle breathing frames, not different designs or poses: frame1 neutral open eyes wings relaxed tail curled; frame2 chest gently expands, head tilts a degree, wing tips lift slightly; frame3 chest expanded, eyelids half closed, tail tip begins to uncurl; frame4 eyes fully closed in a soft blink, wings slightly open, tail tip curled outward; frame5 eyelids half open, chest exhaling, wings easing back; frame6 eyes open and warm slight head tilt, tail tip relaxing; frame7 almost neutral; frame8 exactly matches frame1. Foot position, body proportions, color, crystal shapes, scale pattern must remain extremely consistent. Only ANATOMICAL movement of eyelids, chest, wing joints, and tail; not translated or rotated whole sprites. Polished detailed fantasy-game animation, same rendering quality as reference. Row-major playback left to right then next row. Absolutely no duplicates of heads within any cell, no detached body parts.
